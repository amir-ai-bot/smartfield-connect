SmartField Connect
Project Info
This is a modern web and mobile application built to streamline field operations, improve communication, and centralize task management between field teams and administrators.
How to Run the Project
There are several ways to run and develop this project.
Run Locally (Recommended)
Requirements
Node.js
npm (or yarn)
You can install Node.js using nvm if needed.
Steps
Bash
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate into the project
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start development server
npm run dev
The application will start with auto-reloading and live preview.
